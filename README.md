# Thiệp Cưới Online - Giao Diện Bustle VIP

Giao diện thiệp cưới điện tử hiện đại, responsive, đầy đủ tính năng cao cấp từ mẫu Bustle VIP.

## 🌟 Tính năng nổi bật
- **Hiệu ứng phong bì mở thiệp**: Cánh cửa 2 bên mở mượt mà kèm con dấu sáp và âm nhạc.
- **Đĩa than xoay phát nhạc**: Tích hợp nhạc nền đám cưới, điều khiển phát/tạm dừng.
- **Hiệu ứng hạt rơi**: Trái tim và ánh sáng bay lơ lửng.
- **Tabs Chân dung**: Chuyển đổi linh hoạt giữa cô dâu và chú rể.
- **Đồng hồ đếm ngược**: Tự động tính thời gian thực đến ngày cưới (Ngày, Giờ, Phút, Giây).
- **Bộ sưu tập ảnh cưới (31 ảnh)**: Trình xem ảnh Lightbox toàn màn hình, vuốt cảm ứng trên điện thoại.
- **Sự kiện cưới & Bản đồ**: Tích hợp Google Maps chỉ đường và thêm sự kiện vào Google Calendar.
- **Xác nhận tham dự (RSVP)**: Lưu trữ thông tin khách mời vào LocalStorage.
- **Hộp mừng cưới**: Mã QR chuyển khoản cho cả Chú rể và Cô dâu, nút copy STK và liên kết Zalo.
- **Sổ lưu bút**: Gợi ý lời chúc, gửi lời chúc phúc và thả tim tương tác.
- **Thanh công cụ nhanh**: Quick Action Dock nổi phía dưới màn hình.

## 🚀 Khởi chạy trên máy (Local)

1. Cài đặt Node.js nếu chưa có.
2. Khởi chạy máy chủ:
```bash
npm run dev
# hoặc
node server.js
```
3. Mở trình duyệt truy cập: [http://localhost:3000](http://localhost:3000)
